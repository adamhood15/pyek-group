How to Use This Component

1. Copy the Banner Code

Copy everything between the "PROMOTION BANNER COMPONENT" comments (both HTML and JavaScript) and paste it into your website's HTML, preferably right after the opening <body> tag.

2. Update Campaign Configuration

In the JavaScript section, update the CAMPAIGN_CONFIG object:

  • campaignId: Change this for each new campaign to make the banner reappear
  • messageText: Your promotional message (keep it short!)
  • ctaText: Button text (e.g., "Buy Tickets", "Learn More")
  • ctaUrl: Where the button should link to
  • backgroundColor: Optional custom background (leave empty to use default color)

3. Customize Brand Colors

Update the CSS variables in the :root section to match your brand:

  • --primary
  • --secondary
  • --tertiary
  • --pink
  • --yellow

4. Testing

Use the demo controls above to:

  • Reset Banner: Clear localStorage to show the banner again
  • Simulate New Campaign: See how changing the campaign ID works
  • Check Status: View current banner state in console

5. Analytics Integration

Add your analytics tracking code in the CTA click event listener (marked in the JavaScript section).
