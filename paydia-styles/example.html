Paydia Styles - Implementation Example

This page demonstrates how to include and use the modular Paydia CSS files.

Usage Options

1. Single Master File (Simplest)

<link rel="stylesheet" href="paydia-styles/paydia-styles.css">

Pros: Simple, one file

Cons: Loads all styles even if not needed

2. Individual Modules (Best Performance)

<link rel="stylesheet" href="paydia-styles/01-variables.css">
<link rel="stylesheet" href="paydia-styles/02-base-layout.css">
<link rel="stylesheet" href="paydia-styles/04-product-cards.css">
<!-- Only include what you need -->

Pros: Only load what you need

Cons: Multiple HTTP requests (use HTTP/2)

3. Build Process (Production)

Concatenate and minify all files into one:

cat *.css | cssnano > paydia-styles.min.css

Pros: Single optimized file

Cons: Requires build step

Customization

Update Colors

Edit 01-variables.css or override in your HTML:

<style>
  :root {
    --blue: #0066cc;      /* Your primary color */
    --blue-light: #3399ff; /* Your accent color */
    --red: #cc0000;       /* Your error color */
  }
</style>

Update Spacing

:root {
  --spacing-xs: 8px;
  --spacing-sm: 16px;
  --spacing-md: 24px;
  --spacing-lg: 32px;
}

Page Classes Required

Add one of these classes to the <body> tag:

  • body.page.kissimmee-parties
  • body.page.orlando-parties
  • body.page.renew-season-pass
  • body.page.season-pass
  • body.page.buy-tickets

Example:

<body class="page buy-tickets">

Performance Tips

  1. Preload critical CSS: 
    <link rel="preload" href="01-variables.css" as="style">
  2. Lazy load non-critical modules: 
    <link rel="stylesheet" href="06-utilities.css" media="print" onload="this.media='all'">
  3. Minify for production: 
    npx cssnano paydia-styles.css paydia-styles.min.css
  4. Use HTTP/2 or combine files to reduce requests
